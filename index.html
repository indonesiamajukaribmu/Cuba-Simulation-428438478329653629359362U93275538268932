🔒 Pelindung Data — Sistem Pengaman Anti-Hacker & Anti-Peretas

🔒 Pelindung Data Kubah Simulasi

PROTECTION ACTIVE

Pelindung Data adalah lapisan pengaman terluar kubah simulasi yang mencegah hacker, peretas, dan serangan luar masuk ke Fasilitas Mata. Saat hacker mencoba menerobos dari luar, pelindung mendeteksi via sinyal jaringan, lalu memblokir melalui 8 tahap pertahanan: Hacker Detection → Firewall Block → Encryption Verify → Intrusion Prevention → Threat Analysis → Auto-Quarantine → Log Archive → Alert Notification. Setiap hacker yang diblokir menambah process points Breaches dan menjaga Firewall Integrity tetap 100%.

Teknologi Pendukung

Sensor Android

Perangkat Android sebagai node deteksi komplementer untuk verifikasi multi-sumber.

  • Akselerometer — getaran akibat benda masuk
  • Gyroscope — orientasi & kemiringan kubah
  • Magnetometer — kompas arah benda
  • Proximity — jarak dekat perimeter

Cloud Data Storage

Penyimpanan terdistribusi untuk arsip identitas benda dan analitik pola historis.

  • Time-series DB (InfluxDB) — log deteksi
  • Object Storage (S3) — snapshot container
  • Hot cache Redis — dashboard live
  • Backup terenkripsi AES-256

Sinyal Jaringan

Lapisan transport andal yang menghubungkan sensor → gateway → cloud → dashboard.

  • MQTT over TLS — pesan async ringan
  • Wi-Fi 6 / LoRaWAN — radio adaptif
  • WebSocket — push dashboard live
  • End-to-end TLS 1.3
