Kubah (Dome)

Sistem Kuatro Sensor Dome memanfaatkan empat sensor (PIR, MMW radar, LIDAR, dan Camera IoT) yang dipasang mengelilingi kubah. Begitu objek memasuki pusat area, sinyal deteksi dari sensor diteruskan melalui jaringan gateway ke cloud server, lalu ditampilkan pada dashboard pengguna secara real-time. Teknologi pendukung mencakup sensor Android (akselerometer/gyro) dan penyimpanan cloud data untuk arsip kejadian.

Teknologi Pendukung

Sensor Android

Pemanfaatan sensor bawaan perangkat Android sebagai node deteksi tambahan (komplementer).

  • Akselerometer — deteksi getaran/guncangan kubah
  • Gyroscope — orientasi & kemiringan
  • Magnetometer — kompas arah objek
  • Proximity — jarak dekat pintu kubah

Cloud Data Storage

Penyimpanan terdistribusi berbasis object storage untuk arsip kejadian dan analitik historis.

  • Time-series DB (InfluxDB) — log deteksi
  • Object Storage (S3-compatible) — snapshot kamera
  • Hot cache Redis — dashboard real-time
  • Backup terenkripsi AES-256

Sinyal Jaringan

Lapisan transport yang menghubungkan sensor → gateway → cloud secara andal dan aman.

  • MQTT over TLS — pesan ringan async
  • Wi-Fi 6 / LoRaWAN — radio adaptif
  • WebSocket — push dashboard live
  • End-to-end encryption (TLS 1.3)
